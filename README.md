# Installation

## Prerequisites

- Python 3.11 or higher
- MacOS

## Method 1: Terminal (Recommended)

`curl -o setup.sh https://raw.githubusercontent.com/29LHR/StockTrack/refs/heads/main/installer/setup.sh && bash setup.sh`

## Method 2: Manual

1. Download the Github Repo

### Method 1:

2. Run the `./installer/setup.sh` script using bash
3. Follow Setup Wizard

### Method 2:

2. Install requirements using `pip3 install -r requirements.txt`
3. Run setup.py
4. Delete setup.py
